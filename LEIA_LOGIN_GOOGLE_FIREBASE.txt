=====================================================
 COMO CONFIGURAR O LOGIN COM GOOGLE (FIREBASE)
=====================================================

Se voce esta vendo o erro:
"Erro no login Google: configuracao SHA-1/SHA-256 do Firebase
 nao confere com este APK"

Siga estes passos:

-----------------------------------------------------
PASSO 1 - Criar projeto no Firebase
-----------------------------------------------------
1. Acesse: https://console.firebase.google.com/
2. Clique em "Adicionar projeto"
3. De um nome ao projeto (ex: jogo-educativo)
4. Siga os passos ate concluir

-----------------------------------------------------
PASSO 2 - Ativar Login com Google
-----------------------------------------------------
1. No painel do Firebase, va em "Authentication"
2. Clique em "Sign-in method"
3. Ative o provedor "Google"
4. Adicione seu email como email de suporte
5. Salve

-----------------------------------------------------
PASSO 3 - Adicionar dominio autorizado
-----------------------------------------------------
1. Em Authentication > Settings > Authorized domains
2. Adicione seu dominio do GitHub Pages:
   seu-usuario.github.io

-----------------------------------------------------
PASSO 4 - Configurar para WEB (GitHub Pages)
-----------------------------------------------------
1. No Firebase Console, va em Configuracoes do projeto
2. Clique em "Adicionar app" > Web (</>)
3. Registre o app com um nome
4. Copie o firebaseConfig gerado
5. Cole no arquivo script.js, substituindo:
   - SUA_API_KEY
   - SEU_PROJETO.firebaseapp.com
   - SEU_PROJETO
   - etc.

-----------------------------------------------------
PASSO 5 - Configurar SHA-1/SHA-256 (para APK Android)
-----------------------------------------------------
Se voce esta usando o app como APK (WebView/TWA):

1. Abra o terminal e execute:
   keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android

2. Copie o valor de SHA1 e SHA256

3. No Firebase Console:
   - Va em Configuracoes do projeto
   - Na secao "Seus apps", selecione o app Android
   - Clique em "Adicionar impressao digital"
   - Cole o SHA-1
   - Repita para o SHA-256

4. Baixe o novo google-services.json e coloque no projeto

-----------------------------------------------------
PASSO 6 - Para APK de RELEASE
-----------------------------------------------------
Se voce assinou o APK com outra chave:

1. Use o comando com SUA keystore:
   keytool -list -v -keystore sua-keystore.jks

2. Adicione o SHA-1 e SHA-256 da chave de release
   no Firebase Console

3. Se usa Google Play App Signing:
   - Va em Google Play Console
   - Release > Setup > App signing
   - Copie o SHA-1 do certificado de assinatura
   - Adicione no Firebase

-----------------------------------------------------
RESUMO
-----------------------------------------------------
- Para WEB: Configure o firebaseConfig no script.js
  e adicione o dominio em Authorized domains
- Para APK: Adicione SHA-1 e SHA-256 no Firebase
- O login so funciona com dominios autorizados
- Teste primeiro no navegador antes de gerar APK
