# Jogo Educativo 2.2

Jogo educativo feito em HTML, CSS e JavaScript. Aprenda palavras em portugues e ingles jogando!

## Funcionalidades

- Jogos de palavras em Portugues e Ingles
- Monte a palavra com letras embaralhadas
- Sistema de XP, niveis, moedas e vidas
- Loja para comprar itens com moedas
- Avatares personalizaveis
- Ranking de jogadores
- Login com Google (Firebase Auth)
- **Coruja Cosmica** - animacao interativa com Canvas

## Estrutura dos Arquivos

```
index.html         - Pagina principal do jogo
style.css          - Estilos do jogo principal
script.js          - Logica do jogo, loja, avatar e Firebase Auth
coruja.html        - Pagina da animacao da Coruja Cosmica
coruja.css         - Estilos da pagina da coruja
coruja.js          - Animacao Canvas da coruja cosmica
manifest.json      - Web App Manifest (PWA)
LEIA_LOGIN_GOOGLE_FIREBASE.txt - Instrucoes para configurar login Google
```

## Como Usar

1. Abra `index.html` no navegador ou acesse via GitHub Pages
2. Escolha seu nivel de dificuldade
3. Jogue para ganhar XP e moedas
4. Compre itens na loja e personalize seu avatar
5. Clique em "Coruja Cosmica" para ver a animacao

## Login com Google

Veja o arquivo `LEIA_LOGIN_GOOGLE_FIREBASE.txt` para instrucoes de configuracao.

## GitHub Pages

O projeto e compativel com GitHub Pages. Para publicar:
1. Va em Settings > Pages
2. Selecione a branch `main` e pasta `/ (root)`
3. Salve e acesse pelo link gerado
